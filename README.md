# Иван Рейс — «Холодный космос»

Лендинг реального электронного артиста Ивана Рейса: рабочий плеер с настоящими
превью треков (Apple Music), клипы с YouTube, реальные ссылки на все площадки.

**Live:** https://ivanreys.vercel.app (Vercel-проект `ivanreys`; старый проект briz-landing удалён 2026-07-23)

## Стек
Один самодостаточный `index.html` — без сборки и зависимостей. HTML + CSS + ванильный JS.

## Что внутри
- Плеер на WebAudio: играют настоящие 30-сек превью, волна реагирует на частоты трека,
  перемотка кликом, громкость, mute; при смене трека меняется обложка альбома
- Космический герой на canvas: туманность и звёзды пре-рендерятся в слои,
  на кадр — 4 блита; цикл полностью останавливается вне вьюпорта и в скрытой вкладке
- Ассеты: планета/луна пережаты в WebP (2.9 МБ → 0.2 МБ), preload LCP-картинки
- `content-visibility:auto` на секциях ниже фолда, YouTube-фасады (iframe только по клику)
- Светлая/тёмная тема, prefers-reduced-motion, честные данные артиста (без выдумки)

## Запуск
Открыть `index.html` в браузере. Деплой: `vercel deploy --prod --yes`.
