# Бриз — лендинг

Концепт-лендинг для вымышленного продукта **«Бриз»** — ИИ-конструктора сайтов
(«опишите идею словами — получите готовый сайт за минуту»).

Сделан по мотивам чистого пастельно-градиентного шаблона Figma Sites: минимализм,
живые mesh-градиенты, чёрные pill-кнопки, карточки, чередующиеся секции, бегущая
строка логотипов, футер.

## Стек
Один самодостаточный `index.html` — без сборки и зависимостей. Чистые HTML + CSS + ванильный JS.

## Возможности
- Интерактивное демо в герое: печатающее поле ввода + анимация «генерации» сайта
- Светлая и тёмная тема (переключатель в шапке, запоминается в localStorage)
- Scroll-reveal, hover-микроинтеракции, залипающий навбар с блюром, count-up статистики
- Полностью адаптивно; уважает `prefers-reduced-motion`

## Запуск
Открыть `index.html` в браузере. Хостинг — статикой где угодно (Vercel, Netlify, GitHub Pages).
